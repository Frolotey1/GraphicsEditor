# GraphicsEditor

## Описание
Приложение для создания и редактирования графических фигур.

## Функции
- Создание фигур: прямоугольник, эллипс, линия, текст, многоугольник
- Рисование произвольного контура
- Перетаскивание, копирование, удаление фигур
- Сетка с настраиваемым размером
- Сохранение в PNG, JPG, BMP, PDF
- Открытие изображений
- Сохранение настроек через QSettings

## Технологии
- C++17
- Qt 6.11.2
